JavaRestClient ​

基础 ​

查询 ​

SearchRequest request = new SearchRequest("indexName");
request.source()
        .query(QueryBuilders.matchAllQuery());
SearchResponse response = client.search(request, RequestOptions.DEFAULT);

解析 ​

SearchHits searchHits = response.getHits();
//查询总条数
long total = searchHits.getTotalHits().value();
SearchHit[] hits = searchHits.getHits();
for(SearchHit hit : hits) {
    String json = hits.getSourceAsString();
    sout(json);

}

构建查询条件 ​

同Builder创建对象，使用对象的API即可

排序和分页 ​

request.source().from(0).size(5);
request.source().sort(”字段“,SortOrder.Desc)
.sort();

高亮API ​

加tag ​

request.source().highlight(
    SearchSourceBuilder.highlight()
    .field("字段")
    .preTag("<em>")
    .postTag("</em>")
)

解析 ​

//得到source 
String source = hit.getSourceAsString();
ItemDoc item = JSONUtil.toBean(source,ItemDoc.class);
Map<String,HighlightField> hfs = hit.getHighlightFields();
if(CollUtils.isEmpty(hfs)) {
    HighlightField hf = hfs.get("高亮字段名");
    if(hf != null) {
        //这里的hf可能是由多个数据组成的，这里只取第一个正常需要组合
        String hfName = hf.getFragment()[0].string();
        item.setName(hfName);
    }
}

java与聚合 ​

request.source().size(0);
request.source().aggregation(
    AggregationBuilders
    .terms("聚合name"） //.term 代表聚合类型
    .field("字段")
    .size(20)
);

解析 ​

Aggregations aggregations = response.getAggregation();
Terms brandTerms = aggregations.get("聚合name");
List<? extends Terms.Bucket> buckets = brandTerms.getBuckets();
for(Term.Bucket bucket : buckets) {
    String brandName = bucket.getKeyAsString();
    sout(brandName); 
}
